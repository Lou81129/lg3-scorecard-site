v97.0 — 6-Card Session Support + Cards-to-Print Selector + 7:59 AM Tee Time Enhancement

The LG3 weekly field grew to require up to six scorecards per session — 24 golfers on Thursdays, 20 on Tuesdays. v97.0 fully supports both without printing blank cards.

7:59 AM Tee Time

  • 7:59 AM added as the first option in the Tee Time dropdown — covering Tuesday's earliest pairing
  • MP_TEE_MAP updated: 7:59 AM → Match 0 — 7:59 AM

6-Card Expansion

  • CARDS session array expanded from 4 → 6 blank cards
  • Card 5 and Card 6 tab buttons added to the setup panel
  • All sync and restore loops extended to cover all six cards

Cards-to-Print Selector

  • New "Cards to Print" dropdown in the setup bar — choose 2, 3, 4, 5, or 6
  • Card tabs beyond the selected count are hidden automatically
  • If you switch to a lower count while on a hidden card, the app jumps back to the last visible card
  • Print All Cards only generates sheets for the selected count — no blank cards wasted

v97.1–v97.7 — Flighted Low Gross / Low Net Scorecard New Format

A brand-new competition format added to the LG3 scorecard system. The field is divided into three handicap flights — each flight crowns its own Low Gross winner and Low Net winner. The same player cannot win both; if the leader in gross also leads in net, net goes to the next player in that flight.

Key principle: Flights are assigned by GHIN Handicap Index, not by playing handicap. Indexes are stable across tees and give the fairest, most consistent way to group the field regardless of which tees a player uses.

Flight Assignments

FlightGHIN Index RangeWinners
A8.7 – 12.3Low Gross & Low Net
B12.7 – 19.0Low Gross & Low Net
C21.5 – 28.2Low Gross & Low Net

Any GHIN Index outside the defined ranges displays FLT ? on the card — a flag to verify the player's index before printing.

Card Layout

Each player occupies two rows across all 18 holes:

GROSSScarlet-light (#F8E7EA)Last name • FLT A/B/C badge • Tee, CH, GHIN Index • stroke dots in scarlet

  • Stroke dots appear on the correct holes based on each player's individual Playing Handicap and their tee's Stroke Index
  • OUT, IN, and TOT subtotal boxes on both the GROSS and NET rows
  • Color palette: Scarlet & Grey (Ohio State PMS 200 / PMS 429) — instantly distinguishable from the green stroke play card

Setup & Selection

  • Select Flighted LG/LN from the Select Game dropdown in Scorecard Setup — no separate button required
  • Enter each player's GHIN Index in the index field — the card auto-assigns and displays the correct flight badge
  • All four player fields (name, tee, gender, index) function identically to other card formats

Refinement History (v97.1 → v97.7)

v97.1 — Initial Build New

  • assignFlight() and buildFlightedCard() functions created
  • Scarlet & Grey palette wired into setMode(), refreshHeader(), and toggleBack()
  • Back panel Flight Table and rules content authored

v97.2 — Bug Fixes + Dropdown Integration Bug Fix

  • GHIN field ID corrected — function was reading p0index but the actual input IDs are p0ghin. This caused all GHIN values to return empty, breaking flight assignment and handicap calculation
  • Stroke dot calculation fixed — makeDots() was scoped inside buildSinglesCard() and invisible at the global level; replaced with an inline per-player calculation using each player's own tee Stroke Index data
  • Standalone Flighted LG/LN button removed; format moved into the Select Game dropdown for consistency with all other game modes

v97.3 — Back Panel Restructure Design

  • Flight Table moved from col 3 → col 2 (center)
  • Weekly Game Notes text box restored in col 3 (right) — previously hidden in flighted mode
  • Scarlet palette correctly applied when toggling to the back side in flighted mode

v97.4 — Text Size Increase Enhancement

  • All font sizes increased for senior readability: player name 9pt→12pt, NET label 7.5pt→10pt, hole numbers 7pt→9pt, GROSS label 6pt→8.5pt, and more
  • Row heights also increased at this stage — later reverted in v97.7 to fix print clipping

v97.5 — Stroke Dot Refinement Design

  • Stroke dots reverted to original 5pt size — the 11pt dots introduced in v97.4 overlapped score entry space
  • font-weight: 900 retained — dots are darker and crisper without being oversized
  • GROSS row dot: full scarlet (#BA0C2F); NET row dot: darkened to #444

v97.6 — NET Row Label Cleanup Design

  • Removed "PH: scratch" and "− = stroke hole" text from the NET row label cell
  • NET row label now shows only "NET" — cleaner, less cluttered

v97.7 — Print Sizing Fix Bug Fix

  • Row heights reverted to match the standard LG3 card dimensions:
